# Монополия · Казань

Онлайн-монополия на улицах Казани. Валюта — граммы золота.

## Запуск у себя

```
npm install
npm start
```

Откройте http://localhost:3000, создайте комнату и отправьте друзьям ссылку.

## Выкладка на Render

1. Залейте папку `kazan-monopoly` в репозиторий на GitHub.
2. На render.com нажмите **New → Blueprint** и выберите репозиторий. Render прочитает `render.yaml` сам.
   Вручную: **New → Web Service**, Build Command `npm install`, Start Command `npm start`, тариф Free.
3. Через пару минут игра будет доступна по адресу вида `https://kazan-monopoly.onrender.com`.

На бесплатном тарифе сервер засыпает после 15 минут без посетителей, а первое открытие после сна занимает около минуты.
Партии хранятся в памяти, поэтому при перезапуске или засыпании сервера они пропадают.

## Файлы

- `server.js` — сервер и все правила игры
- `public/board.js` — поле, цены и карточки (меняйте названия и цены здесь)
- `public/client.js` — интерфейс и эффекты
- `public/style.css` — внешний вид
